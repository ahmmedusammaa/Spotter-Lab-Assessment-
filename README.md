# Freight Rate Prediction Challenge

Predicts `posted_rate` for freight loads. Validation is **time-based** (the real test set is Nov–Dec 2025,
after the last training date) and the final model is a robust blend of gradient boosting and ridge regression.

## Run it

Python 3.10+. Dependencies are only `matplotlib`, `numpy` and `pandas` (no scikit-learn). The notebook additionally needs `pip install jupyter`.

```bash
python -m pip install -r requirements.txt

# data/ must contain: train_test.csv, validation.csv,
#                     validation_predictions_template.csv, december_chart_inputs.csv
python run_pipeline.py --data-dir data

python score.py --predictions validation_predictions.csv --december-predictions data/december_chart_inputs.csv
```

`run_pipeline.py` takes about 3–4 minutes (pure-numpy boosting). It has no randomness, so the outputs are reproducible.
It writes `validation_predictions.csv` and fills the `predicted_rate` column of `data/december_chart_inputs.csv` in place.

## Method in short

| Step | Choice |
|---|---|
| Split | 3 expanding-window time folds (train before, test on next 2 months; last fold = Sep–Oct) |
| Target | `log(posted_rate)`, converted back with `exp` |
| Negative `weight` (292 rows) | `abs()` + `weight_bad` flag |
| Missing `weight` / `market_index` (<1%) | median by equipment / by month, learned from training data only; `*_missing` flags |
| Model | 0.8 x gradient boosting (absolute-error loss) + 0.2 x ridge on distance/equipment, averaged in log space; both implemented in numpy in `src/freight.py` |
| Baselines | naive median rate-per-mile; ridge on distance + equipment |

Average over the 3 time folds: MAPE 5.15%, MAE $121, versus 6.69% / $158 for the linear baseline and 10.53% / $219 for the naive baseline.
These are my own validation estimates; the official score is computed by Spotter after submission.

## December chart assumption

`december_chart_inputs.csv` contains only the date, while the model also needs coordinates, `market_index` and `quote_signal`.
Coordinates are copied from other Lexington / Fort Wayne rows; `market_index` and `quote_signal` are the daily averages of the
December rows in `validation.csv`. See `build_december_features` in `src/freight.py`.
